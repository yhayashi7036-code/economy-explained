# 経済と政策の見方

経済指標と中央銀行の仕組みを、公式資料をもとに一般向けに解説する静的Webサイトです。第一版はCPI、GDP、米国FOMC、日本銀行金融政策決定会合、ECB理事会の5記事で構成します。

## 公開先

[経済と政策の見方（GitHub Pages）](https://yhayashi7036-code.github.io/economy-explained/)

## 技術

HTML / CSS / JavaScript。GitHub Pagesの `main / root` から配信し、実行時のサーバーやデータベースを必要としません。

## ローカル確認

プロジェクトのルートで実行します。

```bash
python3 -m http.server 8000
```

`http://127.0.0.1:8000/` を開いてください。

## 編集方針

一次情報を優先し、更新される数値や会合日程は公式資料で確認できるようにします。本サイトは投資助言や個別の税務・法律助言を提供しません。サイト上のデータ取扱いは [プライバシーについて](privacy.html) を参照してください。
